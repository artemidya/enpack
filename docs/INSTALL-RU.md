# DirectEnpack для CorelDRAW 27 — диагностическая сборка 1

**Это тестовая диагностическая сборка x64, не подтверждённый рабочий релиз.**
Собрана для проверки проблемы отсутствующей кнопки в CorelDRAW Graphics Suite 2026 **27.2.0.135** под Windows 10 Pro. В настоящем CorelDRAW эта сборка ещё не проверена.

Алгоритм раскроя, окно параметров, обработчики событий и иконки оставлены как в оригинале. Изменены загрузка, создание кнопки и освобождение ресурсов при завершении. При недоступной или скрытой панели Standard используется отдельная панель DirectEnpack. В исходном коде также остаются другие ограничения оригинала; эта сборка не является полной проверкой его безопасности или устойчивости.

## Установка для проверки

1. Сохранить документы и **полностью закрыть CorelDRAW**, включая другие запущенные экземпляры.
2. Сделать резервную копию установленного `DirectEnpackx64.cpg` **вне папки Addons**. Не оставлять рядом второй файл с расширением `.cpg`: Corel может загрузить оба.
3. Распаковать архив `DirectEnpack-27-diagnostic-1.zip`. Скопировать из него **только** `DirectEnpackx64.cpg` в:

   ```text
   C:\Program Files\Corel\CorelDRAW Graphics Suite\27\Programs64\Addons
   ```

   Подтвердить замену файла и запрос Windows на запись в Program Files, если появится. Для самой проверки запускать CorelDRAW обычным способом, не обязательно от администратора.
4. Если в свойствах скачанного архива есть отметка блокировки, после проверки происхождения файла можно выбрать «Разблокировать» и распаковать заново. Не отключать антивирус или защиту Windows. Сборка не подписана цифровой подписью.
5. Запустить CorelDRAW, дождаться появления интерфейса. Проверить кнопку «Прямоугольный раскрой» на панели «Стандарт» / Standard либо отдельную панель **DirectEnpack**.
6. Нажать **Win+R**, ввести:

   ```text
   %TEMP%\DirectEnpack-27.log
   ```

   Сохранить копию этого файла и отправить для анализа вместе с результатом: появилась ли кнопка, доступна ли она после выделения объектов, открывается ли окно. При закрытии CorelDRAW журнал дополняется записями завершения. Журнал не содержит документов или лицензии, только этапы запуска и коды результатов; он дописывается между запусками.

## Если журнал не появился

Это может означать, что CorelDRAW не вызвал `AttachPlugin`, либо запись во временную папку не удалась. Само по себе отсутствие журнала **не устанавливает причину**. Нужны отчёт `DirectEnpack-diagnostics.txt` и скриншот папки Addons с видимыми расширениями файлов. Если CorelDRAW запущен под другим пользователем, журнал будет в его TEMP.

Если CorelDRAW перестал запускаться: закрыть его, убрать тестовый `.cpg` из Addons и вернуть резервную копию оригинала. Не сбрасывать рабочее пространство и не переустанавливать программу.

## Проверка раскроя — только после успешного запуска

Использовать новый тестовый документ или копию, не рабочий оригинал.

- Создать несколько прямоугольников разного размера и выделить их.
- Открыть плагин, проверить ширину/высоту листа и отступ, выполнить раскладку.
- Отдельно проверить «Перемешать», «Добавить рамку», остановку поиска закрытием окна, отмену результата в CorelDRAW.
- Сравнить результат с привычным поведением оригинала. Выбор раскладки при перемешивании может отличаться.
- Перезапустить CorelDRAW и проверить, что кнопка не дублируется.

При сбое прекратить тест и прислать журнал и описание действий.

## Откат

Закрыть CorelDRAW. Удалить тестовый `DirectEnpackx64.cpg` из Addons и вернуть сохранённый оригинал. Журнал `%TEMP%\DirectEnpack-27.log` и временную иконку `%TEMP%\DirectEnpack-27.ico` можно удалить после закрытия CorelDRAW. Созданная отдельная панель объявлена временной; кнопка на Standard использует тот же идентификатор команды, что и оригинал.
