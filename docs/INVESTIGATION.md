## Статический анализ

Предоставленный CPG — AMD64 Windows DLL с экспортом AttachPlugin. Зависимости в таблице импорта — KERNEL32.DLL и USER32; это не x86-файл и не плагин, требующий отдельной среды .NET. Факт загрузки в процесс CorelDRAW не установлен.

Сравнение исходного `CorelDraw.inc` с предоставленной библиотекой:

- [Оригинал: 35 методов и 3 события, 0 расхождений](abi-upstream-27.2.md).
- [Диагностическая версия: 38 методов и 3 события, 0 расхождений](abi-diagnostic-27.2.md).

Первая предварительная проверка находила 34 метода; полный разбор учитывает также вызовы `IVGShape.SetPosition` через выражение указателя и проверяет **35**. Проверяется положение методов, а не полное двоичное соответствие всех аргументов/соглашений или семантика реализации CorelDRAW.

В оригинале обнаружены потенциально проблемные места запуска:

- отсутствие проверок результатов COM-вызовов перед разыменованием полученных интерфейсов;
- жёсткая привязка к панели Standard;
- поиск кнопки начиная с Item(Count) без проверки Count=0;
- получение двух LONG-номеров версии в перекрывающиеся адреса (разница в один байт), затрагивающее также следующий буфер;
- отсутствие освобождения BSTR, возвращаемых Get_Caption.

Эти места исправлены или защищены **в диагностическом пути запуска**, но ни одно ещё не подтверждено причиной симптома пользователя. Таблицы интерфейсов не менялись.

## Следующий шаг

Пользователь устанавливает диагностическую сборку вместо оригинала по [инструкции](INSTALL-RU.md), проверяет появление кнопки и присылает `%TEMP%\DirectEnpack-27.log`.

- Нет журнала: сначала проверить загрузку модуля, фактическое расположение файла и возможность записи в TEMP.
- Есть AttachPlugin, но нет OnLoad: исследовать взаимодействие загрузчика с интерфейсом плагина.
- Есть ошибка HRESULT: работать с конкретным этапом, а не менять номера COM-методов предположительно.
- Есть READY, но кнопки не видно: проверить рабочее пространство/видимость/состояние UI в реальном приложении.
- Появилась кнопка: проверить окно, затем раскрой и откат только на копии документа.

Рабочее пространство не сбрасывается. Автоматического установщика и изменения реестра нет.
