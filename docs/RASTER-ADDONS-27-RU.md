# Bleeds + Seam Carving + WEBP4CDR — CorelDRAW Technical Suite 27 x64

Это адаптированные сборки для **CorelDRAW из Technical Suite 27, Windows 10/11 x64**. Не для Corel DESIGNER/PHOTO-PAINT и не для 32-битной версии. Полная текущая сборка Technical Suite пользователя ещё не уточнена; сверка COM выполнена по ранее предоставленной библиотеке Corel 27.2.

**В самом CorelDRAW эти три сборки пока не проверены.** Windows-тесты проверяют загрузку, интерфейсы, защитные ветки и отдельный drag-and-drop/декодирование, но не заменяют проверку геометрии и интерфейса внутри Technical Suite. Начинайте с копий документов и устанавливайте компоненты по одному.

## Состав

- `Addons/Bleedsx64.cpg` — создание припусков и контуров; нужна кнопка Bleeds.
- `Addons/WEBP4CDRx64.cpg` — перетаскивание статических WebP; кнопки нет.
- `Plugins/SC_x64.8bf` — фильтр Seam Carving; запускается через меню растровых фильтров, не через кнопку CPG.
- `Workspace/New_export-DirectEnpack-SmartDepart-Bleeds.cdws` — последняя подготовленная среда DirectEnpack + SmartDepart с **одной дополнительной кнопкой Bleeds**.
- Исходники, сведения о сборке, лицензии и контрольные суммы — для воспроизводимости, **не для копирования в Addons**.

Рабочие файлы DirectEnpack и SmartDepart в архив не включены: заменять их не нужно. Успех DirectEnpack подтверждён пользователем ранее; подтверждения работы SmartDepart и новых трёх компонентов ещё нет.

## Перед установкой

1. Экспортируйте **нынешнюю** рабочую среду в отдельный CDWS. Сохраните резервные копии документов.
2. Закройте все процессы CorelDRAW. Для Seam Carving при работе должен быть запущен только один экземпляр CorelDRAW 27.
3. Если эти плагины уже установлены, уберите прежние CPG/8bf из загружаемых каталогов в резервную папку. Не оставляйте рядом копии с другим именем: Corel может загрузить обе.
4. Найдите `Programs64\Addons` **именно вашей установленной Technical Suite 27**, рядом с используемым `CorelDRW.exe`. Путь старой Graphics Suite из предыдущих сообщений здесь не использовать. Архив сам ничего не устанавливает и не меняет реестр.

## 1. Bleeds

1. Скопируйте **только** `Addons/Bleedsx64.cpg` в найденную папку Addons.
2. Запустите CorelDRAW.
3. Если используете последнюю подготовленную среду DirectEnpack + SmartDepart и после неё ничего не меняли, импортируйте приложенный CDWS как отдельную среду. **Не сбрасывайте настройки, не применяйте F8, не сбрасывайте панель свойств.**
4. Если после последнего экспорта меняли панели/горячие клавиши/меню, **не импортируйте целиком старый CDWS**. В настройке команд найдите зарегистрированную команду Bleeds/«Припуски» в категории подключаемых модулей и добавьте её на свою панель. Альтернатива — передать актуальный экспорт для точечного дополнения с иконкой.
5. Выделите объект на копии документа и нажмите кнопку. Без выделения кнопка отключена.

Сохраняются исходный диалог, алгоритм трассировки, сглаживание, ширина припуска в мм, группировка, внешние контуры, выбор цветовой модели и слой «рез». Внутренняя растеризация имеет исходные ограничения, описанные в `sources/upstream/Bleeds/Readme.md` (в частности, используется 150 dpi в предусмотренных автором случаях).

Плагин больше не создаёт/не делает видимой собственную панель при каждой загрузке и не пишет временную иконку. Рисунок кнопки взят из **оригинального `Readme/icon.bmp`** — 16×16, 61 чёрный пиксель; белый фон переведён в прозрачность. Отсутствующего в репозитории автора `icon.ico` не было: это восстановление по исходному BMP, не новый рисунок и не извлечение иконки из релизного CPG.

## 2. Seam Carving

1. При закрытом CorelDRAW положите `Plugins/SC_x64.8bf` в отдельную постоянную папку фильтров.
2. В настройках CorelDRAW откройте раздел **«Подключаемые модули / Plug-ins»** и добавьте эту папку в список поиска, либо используйте уже настроенный каталог Plugins. **В Addons файл 8bf не класть.** Не добавляйте сразу всю папку с исходниками.
3. Перезапустите CorelDRAW. Выделите растр RGB или CMYK.
4. Откройте **Растровые изображения → Подключаемые модули → tiny filters → Seam Carving**.
5. Исходные инструменты сохранены: зелёная/красная разметка приоритетов, кисть, масштаб, переключение ширины/высоты, «Применить» и «OK». Закрытие окна отменяет результат; во время расчёта отмена дожидается безопасной точки обработки вместо принудительного уничтожения потока.

Ограничения:
- CPU с SSE4.1; вход от 4×4, не более **4 194 304 пикселей** и **16 384 пикселей по каждой стороне**. Это новые защитные границы, а не обещание обработки растра любого размера.
- RGB с 3 каналами или CMYK с 4; прочие режимы/раскладки отклоняются. Для первого теста используйте обычный RGB-растр без прозрачности. Сохранение альфа-канала не обещается: исходный фильтр также предупреждает об его удалении.
- Угол поворота не учитывается; CMYK-превью имеет исходное ограничение цветопередачи.
- Фильтр привязывается к **уже запущенному CorelDRAW.Application.27**, проверяет процесс и не запускает другую версию через CoCreateInstance. При нескольких экземплярах/неверной регистрации возможен отказ, а не работа с чужим документом.
- Результат, PowerClip, изменение размеров, Undo и повторный запуск необходимо проверить в вашем CorelDRAW. Windows-автотесты этого не доказывают.

## 3. WEBP4CDR

1. При закрытом CorelDRAW скопируйте **только** `Addons/WEBP4CDRx64.cpg` в ту же папку Addons.
2. Перезапустите CorelDRAW; откройте/создайте документ и перетащите из Проводника небольшой статический `.webp` в окно документа. Кнопка и отдельная панель не появляются.
3. CorelDRAW и Проводник должны работать с одинаковым уровнем прав. Не запускайте CorelDRAW «от администратора» без необходимости: Windows может блокировать перетаскивание из обычного Проводника.

Функция исходного проекта сохранена, но **C++-обвязка переписана**, это не простая перекомпиляция старого ASM. Для каждого окна хранится свой исходный OLE drop target. Статический WebP декодируется libwebp **1.6.0** и передаётся штатному обработчику Corel как временный PNG с альфа-каналом. Координаты, клавиши и прочие файлы смешанного перетаскивания передаются обработчику; единицы документа не меняются. Масштаб/размещение определяет штатный PNG-импорт Corel, а не старый код ручного создания растра в миллиметрах.

- Конвертация начинается уже на DragEnter, чтобы Corel мог принять формат.
- Анимация, повреждённые/недоступные WebP отклоняются. Для партии с WebP: до **8 файлов**, до **64 MiB на один закодированный WebP**, суммарно до **16 777 216 декодированных пикселей**. В этой партии ошибка одного WebP отменяет передачу всей партии обработчику, а не импортирует её часть.
- ICC/EXIF/анимационные метаданные WebP не переносятся; это пиксельный импорт. Проверка цветового управления и размера в Corel обязательна для производственных задач.
- PNG создаются в `%TEMP%\WEBP4CDR27-{GUID}`. Для возможного отложенного импорта **файлы не удаляются сразу после Drop/DragLeave**. Они могут содержать изображения из документов. После закрытия всех CorelDRAW эти папки можно удалить вручную. Не удаляйте их во время импорта. Лимит одной загрузки модуля — до 256 созданных PNG и 512 MiB учтённых выходных данных; для сброса полностью закройте CorelDRAW.
- DLL остаётся отображённой в памяти до завершения процесса, чтобы поздний OLE-вызов не попал в выгруженный код. Для замены/отката **нужен полный перезапуск CorelDRAW**. При остановке сессии исходные обработчики восстанавливаются там, где регистрация ещё принадлежит этому плагину; чужая последующая регистрация не перезаписывается.
- Для регистрации на потоке окна используется кратковременный оконный hook только внутри текущего процесса, без подмены WndProc и без сбора клавиатурного ввода. Ожидание передачи запроса ограничено; это не гарантия отсутствия задержек внутри самого Corel.

## Минимальная проверка в Technical Suite

Проверяйте по очереди, на копиях:

1. До установки сохраните вид панелей, горячие клавиши и контрольный документ.
2. Bleeds: один растровый и один векторный объект; изменение ширины; слой «рез»; группа; Undo; документ без выделения; повторный запуск.
3. Seam: небольшой RGB; уменьшение ширины и высоты; разметка приоритетов; отмена в процессе расчёта; повторное открытие; Undo; затем отдельный тест CMYK.
4. WebP: RGB и полупрозрачный WebP; два открытых документа; новое окно после запуска; смешанная партия PNG+WebP; обычный CDR/PNG drag-and-drop без WebP; переключение рабочей среды и повторное перетаскивание. Недопустимый WebP не должен создавать частичный импорт.
5. Убедитесь, что DirectEnpack, SmartDepart, панели и переключение рабочих сред не ухудшились.

Если возникает сбой — остановитесь на этом компоненте, закройте CorelDRAW и откатите его. Сообщите полную версию Technical Suite, имя файла плагина, действие и точный текст ошибки. Не продолжайте тест на единственном экземпляре рабочего документа.

## Откат

При закрытых CorelDRAW удалите новые `Bleedsx64.cpg`, `WEBP4CDRx64.cpg`, `SC_x64.8bf` из загружаемых каталогов (либо верните собственные прежние копии). Вернитесь к сохранённой перед установкой рабочей среде. **DirectEnpack/SmartDepart не удалять и не заменять.** Временные папки WEBP4CDR27 можно удалить только после закрытия CorelDRAW. Сброс всего профиля не требуется.

## Что проверено автоматически

- Слоты ранних COM-вызовов Bleeds/Seam по пользовательской VGCoreAuto 27.2: `docs/raster-abi-27.2.md`, расхождений нет.
- Сохранение всех прежних XML-байтов CDWS после удаления двух добавленных фрагментов, всех прочих ZIP-элементов и их метаданных, исходного рисунка кнопки.
- Выполнение x64 FASM-кода в Unicorn: загрузочные/защитные сценарии, HRESULT, CPUID/nonvolatile-регистры, некорректные события, канонический VARIANT_BOOL, очистка.
- Native Windows x64: загрузка/экспорты; WebP → WIC PNG с проверкой RGBA; отсутствие/повреждение/анимация/лимиты; смешанные файлы; два окна, восстановление/ссылки; регистрация на другом STA-потоке. Отдельно проверяется доставленный CPG и независимая сборка MSVC.
- Регрессионные проверки ранее подготовленных DirectEnpack/SmartDepart/CorelWatch.

**Не проверено автоматически:** реальный CorelDRAW Technical Suite, внешний вид кнопки в вашем профиле, качество трассировки/припусков, полный расчёт seam carving и PowerClip/Undo, все особенности штатного импортёра Corel и совместимость с другими установленными надстройками.
