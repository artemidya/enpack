# SmartDepart для CorelDRAW Technical Suite 27 x64

Комплект основан на исходниках `fersatgit/SmartDepart`, commit **9ff9af3af2dca74ace96179a2e9ef5175777f560** (ветка main, не заявляется побайтовое совпадение с release v1.1). База рабочего пространства — **New_export-DirectEnpack.cdws**, успешную установку которого подтвердил пользователь.

**DirectEnpack оставлен без изменений.** SmartDepart собран заново; работоспособность его операций внутри установленного CorelDRAW пока должен подтвердить пользователь на копиях документов.

## Скачать и установить

Комплект `SmartDepart-27.zip` содержит:

- `plugin/SmartDepart.cpg` — новая сборка x64;
- `New_export-DirectEnpack-SmartDepart.cdws` — рабочее пространство с DirectEnpack и меню SmartDepart;
- `source-original/` — неизменённые исходники автора, лицензия, оригинальные AppUI.xslt/config.xml;
- `source-adapted/` — x64-исходники выданной сборки с исправленным lifecycle;
- `README-RU.md`, отчёты и контрольные суммы.

Порядок:

1. Сохранить документы и сделать резервную копию **текущего работающего** пространства. Новый CDWS — снимок последней известной рабочей базы; более поздние ручные настройки пользователя он не содержит. Не импортировать его поверх единственной рабочей конфигурации без копии.
2. Полностью закрыть CorelDRAW.
3. Если SmartDepart раньше устанавливался, сохранить его старый `.cpg` и/или папку аддона **вне Addons**. Не оставлять одновременно старую папку SmartDepart с AppUI.xslt и новый CPG: получится конкурирующая регистрация одного источника данных. Не трогать DirectEnpack, U2 и другие аддоны.
4. Скопировать **только** `plugin/SmartDepart.cpg` из комплекта в:

   ```text
   C:\Program Files\Corel\CorelDRAW Technical Suite\27\Programs64\Addons\SmartDepart.cpg
   ```

   Если CorelDRAW установлен иначе, использовать Addons рядом с фактически запущенным `CorelDRW.exe`. Работающий `DirectEnpackx64.cpg` оставить как есть; его замена не нужна.
5. Запустить CorelDRAW и импортировать `New_export-DirectEnpack-SmartDepart.cdws` в отдельное тестовое рабочее пространство тем же способом, который сработал для DirectEnpack. В мастере импорта выбрать **«Стандарт»**. Внутренние метаданные имени профиля сохранены от New_export; если предлагается заменить рабочую конфигурацию — сначала выбрать отдельную копию/сделать резервный экспорт.
6. На «Стандарт» рядом с DirectEnpack появится выпадающее меню **SmartDepart**. При нехватке ширины панели проверить список скрытых кнопок в её конце.

**Не копировать source-original/source-adapted целиком в Addons. Не устанавливать AppUI.xslt/config.xml/coreldrw.addon из папки исходников. Не сбрасывать панель свойств или всё рабочее пространство.** В этом комплекте интерфейс и изображения встроены в CDWS, а CPG регистрирует источник данных напрямую. Это отличается от авторской установки через XSLT панели свойств и позволяет избежать её сброса.

## Функции

В меню сохранены все четыре команды оригинального AppUI.xslt:

| Пункт | Привязка к источнику данных |
|---|---|
| Умное деление | SmartDepart / 0 |
| Резка струной | SmartDepart / 1 |
| Триангуляция | SmartDepart / 2 |
| Декомпозиция | SmartDepart / 3 |

Также сохранён регулятор **«Погрешность линеаризации кривых»**, привязка SmartDepart / 4, диапазон **0,01–10 мм**, шаг 0,01 мм; исходное значение в DLL — **0,1 мм**.

Как у автора, меню доступно при подходящем выделении (`CanBreakApart` или `IsValidCombine`). Без выделения оно может быть серым — это не само по себе ошибка загрузки. Для теста использовать замкнутые кривые на новом документе/копии, например составную кривую с внешним контуром и отверстием; не начинать с текста, растров или важных оригиналов.

Алгоритм выполняет преобразование/разделение и удаление исходной объединённой фигуры по логике автора. Проверять операции на отдельных копиях объектов. Для полного пути резки струной автор описывает двукратный вызов функции; см. оригинальный README в source-original.

## Что изменено и что сохранено

### В CPG

FASM 1.73.35, PE32+ AMD64, экспорт AttachPlugin. Алгоритмы, диспетчер Invoke, фабрика данных, таблицы интерфейсов и ресурсы **не менялись** относительно выбранного commit.

Изменён только участок lifecycle (`Lifecycle27.inc`):

- сохранение RBX при CPUID по ABI Windows x64 (оригинальный StartSession его перезаписывал);
- раздельные LONG-поля основной/дополнительной версии вместо записей со смещением в один байт; для алгоритма сохраняется прежнее представление версии;
- проверка SSE4.2 и POPCNT до регистрации источника данных;
- проверки HRESULT/указателей, результата регистрации, корректное освобождение полученных интерфейсов при неуспешной загрузке, защита от повторной регистрации/выгрузки.

Это не полный аудит алгоритмов или всех COM-заглушек автора. В частности, изменения не гарантируют отсутствие ошибок при неподходящих документах.

### В CDWS

Добавлены только три фрагмента XML: ссылка на меню на Standard, семь определений элементов SmartDepart и одна панель выпадающего меню. Добавлены четыре ICO с исходными пикселями, преобразованные в обычный 32-битный формат. Для новых UI-элементов используются отдельные GUID, а имя **источника данных остаётся SmartDepart**.

DirectEnpack, его иконка/команда, существующие меню, состояния, параметры экспорта, settings.ini, Addons/XSLT-ссылки и прочие данные сохранены. Удаление трёх вставок возвращает исходные байты XML; другие существующие ZIP-файлы не менялись. CPG внутри CDWS не хранится и не исполняется — его нужно установить отдельно.

## Проверки и ограничения

- Исходники автора сверены по Git blob SHA с закреплённым commit.
- Сборка FASM выполнена успешно; 28 используемых Corel/UI vtable-слотов и IID ICUIApplication совпали с предоставленной **VGCore 27.2 x64**. Это проверка позиций, не всех сигнатур/поведения API.
- 11 эмулированных сценариев Win64 lifecycle: обычная загрузка, повторная загрузка, null Application, отсутствие SSE4.2/POPCNT, ошибки чтения версии/QI/регистрации, null CUI, отказ регистрации. Проверены стек, nonvolatile-регистры, баланс COM-ссылок, фабрика данных и чтение/запись погрешности.
- Проверены оригинальные привязки четырёх действий, диапазон регулятора, сохранение DirectEnpack, обратимость вставок XML и пикселей иконок.
- **Геометрические операции внутри настоящего CorelDRAW не тестировались.** Эмуляция WinAPI/COM этого не заменяет.
- **Требования x64: SSE4.2 и POPCNT**, как у автора. При отсутствии этих инструкций загрузка отклоняется.

Проверить: меню/переключение окон до вызова, доступность SmartDepart при выделенных кривых, каждую из четырёх операций на копиях, возврат/отмену и повторный запуск CorelDRAW. Проверить отдельно, что DirectEnpack продолжает работать.

## При проблеме / откат

При первой регрессии прекратить тест. Вернуться к сохранённому рабочему пространству. Закрыть CorelDRAW и убрать **только SmartDepart.cpg** из Addons, сохранив его отдельно; DirectEnpack не менять. Не переустанавливать CorelDRAW и не делать общий сброс F8.

Если кнопка есть, но команды не выполняются, проверить путь CPG и отсутствие второй установленной копии SmartDepart. Установленный ранее CorelWatch может записать загруженные модули/состояние окон. SmartDepart в этом комплекте **не создаёт** журнал DirectEnpack-27.log. Наличие импортированного меню само по себе не доказывает загрузку источника данных.

## Сборка для разработчика

В репозитории enpack:

```bash
bash tools/bootstrap-fasm.sh
python tools/build_smartdepart.py
python -m venv .tools/venv
.tools/venv/bin/pip install -r tools/requirements-test.txt
.tools/venv/bin/python tools/test_smartdepart_emulated.py build/SmartDepart.cpg
```

Генерация CDWS дополнительно использует Pillow. Команда `tools/smartdepart_workspace.py` принимает входной работающий CDWS и новое имя результата, отказывается перезаписывать вход или добавлять второй SmartDepart. Для будущего экспорта со значительными изменениями структуры сначала требуется проверить его содержимое.
