# CorelWatch 1.0 — внешний наблюдатель CorelDRAW

Экспериментальная диагностическая утилита для Windows 10/11 x64. Работает **отдельно от CorelDRAW**, без установки плагина или Python. Использует штатный Windows PowerShell 5.1 и компилирует небольшой C#-модуль штатным `Add-Type`.

Это **не перехватчик всех действий/ошибок**, не антивирус и не средство ремонта. Утилита прошла автоматическую проверку Windows PowerShell 5.1 / Win32 и минутный запуск без CorelDRAW: https://github.com/artemidya/enpack/actions/runs/37760197117 . В настоящем CorelDRAW 27.2 ещё требуется пользовательская проверка. Подробности — в репозитории `docs/RECOVERY-AND-MONITOR-RU.md`.

## Быстрый запуск

1. Полностью распаковать архив в отдельную доступную для записи папку, например «Загрузки\CorelWatch». Не запускать прямо из ZIP.
2. Запустить **`Start-CorelWatch.cmd`** обычным двойным щелчком. Не запускать от администратора без необходимости.
3. Оставить окно утилиты открытым, при желании свернуть. Запустить CorelDRAW либо наблюдать уже запущенный экземпляр.
4. Воспроизвести проблему на пустом/тестовом документе: открыть меню, переключиться в другую программу и вернуться. Не выполнять раскрой рабочего оригинала ради диагностики.
5. Перейти в окно CorelWatch:
   - **M** — записать отметку времени «сейчас наблюдал проблему»;
   - **S** — снять дополнительный список загруженных модулей;
   - **Q** — закончить наблюдение и дописать отчёт.
6. Отчёт появится в **`Reports\дата-время-идентификатор`** рядом с утилитой. Просмотреть его, затем упаковать **эту папку сеанса** в ZIP и передать для анализа.

Клавиши читаются только в собственном активном окне консоли. Утилита не перехватывает ввод в CorelDRAW или других программах. Если CorelDRAW не запущен, наблюдатель ждёт его появления.

По умолчанию наблюдение длится **до 20 минут**, интервал — 2 секунды. Объём JSONL-журналов ограничен 50 МиБ. Можно завершить раньше клавишей Q. Закрытие консоли тоже останавливает наблюдение, но итоговый summary/журнал Windows тогда могут не успеть записаться; уже записанные строки сохраняются.

Для другого режима из командной строки:

```bat
Start-CorelWatch.cmd -Label baseline-without-plugin -DurationMinutes 10 -IntervalSeconds 2
```

## Что наблюдается

- Появление и исчезновение процессов `CorelDRW`, PID и время запуска.
- Суммарное процессорное время, память, число потоков и дескрипторов.
- Отвечает ли главное окно на **WM_NULL** с тайм-аутом 150 мс. Это пустое сообщение, не команда рисования или интерфейса; максимум одна проба на процесс за цикл.
- Доступность/видимость окон, их классы, владельцы, координаты, признак выхода за экран, последнее всплывающее окно и состояние GUI-потока. Это помогает отличить вероятное зависание от заблокированного главного окна с модальным диалогом.
- Принадлежит ли текущее активное окно процессу CorelDRAW — без названий и содержимого других приложений.
- Загруженные модули, в том числе `.cpg`: при обнаружении процесса, после трёх последовательных неответов и по клавише S.
- При штатной остановке — доступные записи журнала Windows Application за время сеанса: события 1000/1001/1002/1026, в сообщениях которых встречается CorelDRW или DirectEnpack. Windows не обязана записывать событие для каждого зависания; чтение может быть запрещено политиками.
- Последние до 2000 строк `%TEMP%\DirectEnpack-27.log`, если файл есть и не больше 5 МиБ. Этот хвост может включать записи более ранних запусков.

Один неответ может означать занятость, а не ошибку. Отключённое главное окно нормально при открытом модальном диалоге. Порог «три неответа» — только повод сохранить дополнительное наблюдение, не доказательство deadlock.

## Чего утилита НЕ делает

- Не внедряет DLL, не подключает COM/VBA к CorelDRAW, не ставит глобальные hooks и не меняет его UI.
- Не записывает нажатия клавиш, заголовки окон/имена документов, скриншоты или содержимое документов.
- Не меняет реестр, рабочие пространства, плагины, аудит Windows или настройки CorelDRAW.
- Не добавляет себя в автозапуск и не устанавливает службу.
- Не снимает дампы памяти и не завершает процесс CorelDRAW.
- Не отправляет данные по сети. Единственные постоянные записи — папка отчётов; `Add-Type` может использовать временные файлы компилятора Windows.
- Не видит внутренние вызовы всех плагинов, все команды/клики, стек зависшего потока или все ошибки приложения. Для точного определения зависшего кода может понадобиться отдельный дамп и отладчик.

**Пути модулей и сообщения журнала Windows могут содержать имя пользователя, пути к документам и другие личные сведения.** Перед отправкой просмотреть отчёты. Не публиковать дампы памяти на GitHub: они могут содержать документы, лицензии и другие данные процесса.

## Файлы отчёта

- `session.json` — параметры запуска и ограничения наблюдения;
- `samples.jsonl` — периодические наблюдения процессов/окон (появляется только при наличии CorelDRAW);
- `events.jsonl` — запуск/исчезновение процессов, ошибки самого наблюдателя, пользовательские отметки;
- `modules.jsonl` — снимки модулей и путей;
- `windows-events.jsonl` — подходящие события Windows, если они найдены;
- `DirectEnpack-27-tail.log` — хвост журнала диагностического CPG, если доступен;
- `summary.json` — итог штатно завершённого сеанса.

Отсутствие конкретного файла не обязательно ошибка: например, Windows могла не зарегистрировать ни одного подходящего события.

## Если не запускается

Не отключать антивирус или корпоративные ограничения. В `Start-CorelWatch.cmd` политика `Bypass` применяется только к одному процессу PowerShell, системная политика не меняется. Если организация запрещает выполнение — не обходить её запрет.

Сохранить текст ошибки или скриншот консоли. Для чтения модулей желательно, чтобы CorelDRAW и утилита были запущены с одинаковым уровнем прав; недоступность модулей фиксируется в отчёте, а не вызывает попытку автоматического повышения прав.

Техническая проверка native-модуля без наблюдения CorelDRAW:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\CorelWatch.ps1 -SelfTest
```

После завершения наблюдения утилиту можно удалить вместе с её папкой. Удаление не затронет настройки CorelDRAW.
